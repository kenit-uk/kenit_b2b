# Install Hub v1 범위

기준: `Install_Hub_GUI_시안_v9_한글판.pdf` (2026.10.16)

v1은 **회사 직원(관리자·매니저)과 설치업자가 쓰는 웹 서비스**다. 고객·건설업자 화면은 v1에 넣지 않는다.
설치업자 화면은 휴대폰 기준, 회사 화면은 PC 기준으로 만든다.

## 1. 원칙

- **가격은 설치업자에게 절대 보이지 않는다.** 화면뿐 아니라 서버가 설치업자에게 보내는 데이터에도 금액을 넣지 않는다. 지금 앱의 견적 금액은 설치업자에게 보이므로 v1에서 바꾼다.
- **기록은 지우지 않는다.** 수정하면 이전 내용과 시각이 남고, 작업 기록(Activity log)은 고칠 수 없다.
- **설치업자는 자기 일만 본다.** 배정되지 않은 프로젝트, 다른 설치업자의 일정은 보이지 않는다.
- **위치는 "현장 도착"과 "오늘 작업 끝"을 누를 때 한 번씩만** 저장한다. 백그라운드 추적은 하지 않는다 (UK GDPR).
- 기본 언어는 영국 영어, 한국어는 선택.

## 2. 데이터 구조

```
프로젝트 (주소, 관리번호 WS-xxxxxx-xx, 9단계, 보류 여부, 시스템 유형)
├─ 참여자 (설치업자 배정)
├─ 방문 (현장조사 / 1차 시공 / 2차 시공 / 기타) — 날짜·시간대, 설치업자, 상태(후보·확정·완료)
│   ├─ 날짜 후보 (설치업자가 고른 2~3일)
│   ├─ 현장 도착 / 작업 끝 기록 (시각 + 위치 1회)
│   ├─ 사진 (방 태그)
│   └─ 일일 보고 (한 작업, 문제 여부, 메모)
├─ 현장조사 → 방 카드 (실내기 위치 사진, 형태, 대략 용량, 메모, 액세서리) + 실외기·트렁킹·전기
├─ 작업 범위 (Scope) 버전 v1, v2, v3 … — 방별 기기·용량·액세서리, 프로젝트 공통 사항 (가격 없음)
│   └─ 설치업자 확인 기록 / 의견
├─ 변경 요청 (Variation, VO-1 …) — 시공 금지 / 시공 가능
├─ 자료 (도면, 평면도, LATS, 카탈로그, 협의 기록) — 버전, 확인함 기록
└─ 작업 기록 (감사 로그)
```

**9단계:** 1 현장조사 예약 · 2 현장조사 · 3 견적·범위 협의 · 4 최종 확정 · 5 일정 조율 · 6 1차 시공 · 7 2차 시공 · 8 인수인계 · 9 완료 확인.
단계 이동은 회사만 할 수 있다. 지금의 상태값(검토전 … 보류)은 9단계와 "보류" 표시로 바꾼다.

**지금 데이터 옮기기:** 계정은 그대로, 집 → 프로젝트, 현장정보 기록 → 현장조사 메모와 사진, 견적 → 회사 전용 메모(금액 포함), 집주인 대화 → 회사 전용 메모로 옮긴다.

## 6. 만드는 순서

1. **바탕:** 새 데이터 구조, 지금 데이터 옮기기, 시안 디자인(초록 계열), 모바일 하단 탭과 회사 화면 틀
2. **현장조사:** 설치업자 3a~3c → 회사 현장조사 검토 → 작업 범위 v1 만들기
3. **작업 범위·자료:** 버전 관리와 비교, 설치업자 변경 확인(4), 자료함(11, 12)
4. **방문·현장:** 달력과 예약(7), 날짜 선택(2), 오늘 할 일(1), 현장 도착·사진·작업 끝(6, 7), 변경 요청(8)
5. **승인 대기·프로젝트 상세:** 회사 1, 2 완성, 설치업자·직원 관리(6)

각 단계마다 테스트(SQLite·PostgreSQL)를 통과한 뒤 배포한다.
